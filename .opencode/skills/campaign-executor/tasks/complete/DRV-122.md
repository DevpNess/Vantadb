## Contexto

DRV-121 (CBO planner) was a prerequisite — now ✅ completed. IQL currently supports only single-entity queries (`FROM Person WHERE ...`). No JOINs, no subqueries, no SQL-like `SELECT` syntax. This creates a gap vs Qdrant/Chroma which support richer queries.

Current IQL grammar (`src/parser/mod.rs:155`):
```
FROM entity [SIGUE min..max "edge"] [alias] [WHERE cond1 AND cond2] [FETCH f1,f2] [RANK BY field] [WITH TEMPERATURE t] [ROLE "role"]
```

Logical operators (`src/query.rs:210`): Scan, FilterRelational, VectorSearch, Traverse, Sort, Project.
