# ECO-001: Remove dead Claude Code hooks (C1)

**Estado:** ✅ COMPLETED (commit `cf623e5c`)

## Type
Cleanup — dead code removal

## Problem
`.opencode/hooks/hooks.json` y `session-start.sh` son artefactos de Claude Code que **nunca se ejecutan** en OpenCode sobre Windows:
- `hooks.json` usa el formato PascalCase de Claude Code (`SessionStart`), no el JS plugin API de OpenCode
- `session-start.sh` requiere `bash` y `jq` — ninguno disponible en Windows por defecto
- Usa variables de entorno `CLAUDE_PLUGIN_ROOT`/`CLAUDE_PROJECT_DIR` que OpenCode no define
- El contenido de `using-agent-skills` (lo que intenta inyectar) ya está duplicado en AGENTS.md

## Investigation Notes (2026-07-23)
- OpenCode NO lee `hooks.json` — usa plugin API con hooks como `experimental.chat.system.transform`
- OpenCode no tiene `SessionStart` hook — tiene `session.created` vía plugin JS
- No hay ningún `.ps1` equivalente — el hook nunca fue portado
- `using-agent-skills/SKILL.md` (191 líneas) está disponible manualmente vía `skill using-agent-skills`
- Blast radius de eliminar: **CERO** — ningún flujo, comando, agente o prompt depende de estos archivos
- Ver reporte completo de investigación en sesión C1

## Contract
`.opencode/hooks/` contiene solo 2 archivos que son dead code. El directorio puede eliminarse o dejarse vacío.
