## Contrato
"Job CI `examples` en `.github/workflows/ci-rust-10.yml` (o workflow nuevo `ci-examples-*.yml`) corre: (1) cada example Rust con `cargo run --example <name>` exit 0, (2) cada example Python como smoke con `python <file>.py` exit 0. CI bloquea PRs que rompen examples. Job tarda <10 min en runner ubuntu."

## Herramientas
- bash/pwsh (CI YAML), gh (verificar issue), cargo run para examples Rust.

## Steps
### Step 1: Discovery de examples
- **Archivos:** `examples/rust/*.rs`, `examples/python/*.py`, `examples/demo/*`, `Cargo.toml`
- **Acción:** Inventariar todos los examples; verificar cuáles requieren deps externas (libs framework) vs solo `vantadb_py` + stdlib; revisar si `examples/python/*.py` usan API keys/env vars (OPENAI_API_KEY etc.) que fallearían sin red/secrets.
- **Verify:** lista completa de examples con clasificación smoke-safe.

### Step 2: Agregar job CI de examples Rust
- **Archivos:** `.github/workflows/ci-rust-10.yml` (job nuevo `examples`) o `ci-examples-*.yml`
- **Acción:** job que build + corre los 4 examples Rust (`cargo run --example basic/hybrid/graphrag/concurrent`) con setup estándar (`rust-setup` action, system-deps).
- **Verify:** `cargo run --example basic` y los demás salen 0 localmente.

### Step 3: Agregar job CI de smoke tests Python
- **Archivos:** mismo workflow (job `examples-python` o step)
- **Acción:** instalar Python + build wheel `vantadb_py` (o usar `.venv` / maturin), instalar deps de cada example, correr cada `.py` como smoke. Ejemplos con deps de framework (langchain, haystack, mem0, etc.) — decidir si instalar la lib o marcar como externo; los que requieren API keys se excluyen del smoke o se corren en modo offline si el código lo permite.
- **Verify:** cada example Python corre exit 0 (o documentar exclusión razonada).

### Step 4: Verificación completa + commit
- **Acción:** ejecutar el workflow localmente no es posible; validar YAML con actionlint (pre-commit lo corre), confirmar paths/globs correctos, revisar el YAML completo.
- **Verify:** `cargo run --example` de los 4 Rust exit 0; `python examples/python/*.py` exit 0 (los smoke-safe); actionlint ok.
- **Commit:** `ci: add example smoke tests to CI (GH-142)`.
