# VFY-010: ACID Phase 2 — Buffered Write Transactions

**Type:** `feature-add`
**Sub-agent:** `vanta-worker`
**Effort:** 🟡 2-3d
**Priority:** 🔵
**Plan:** No está en el plan activo de estabilización. Implementación independiente.

---

## Goal

Phase 2 of ACID transactions: buffer writes **in memory** during a transaction instead of writing directly to stores on every `insert()`/`delete()` call. Defer all store I/O (vstore, KV backend, HNSW, cache) to commit time. On abort, discard all buffered writes.

This reduces fsync calls from N-per-write to 1-per-commit, and makes `abort_transaction()` a true zero-cost rollback.

---

## Current State (Phase 1 — already done)

- `begin_transaction()` (ops.rs:104): appends `WalRecord::Begin(txn_id)` to WAL
- `commit_transaction()` (ops.rs:118): appends `WalRecord::Commit(txn_id)` to WAL
- `abort_transaction()` (ops.rs:129): appends `WalRecord::Abort(txn_id)` to WAL
- `insert()` (ops.rs:145): writes directly to WAL, vstore, KV backend, HNSW, and volatile cache — even inside a transaction
- `delete()` (ops.rs:760): same — writes directly to all stores
- Recovery: discards writes from uncommitted/aborted transactions (Phase 1 feature)
- **No in-memory buffering exists yet**

```rust
/// `None` = no active transaction → insert/delete go direct.
pub(crate) active_txn_id: parking_lot::Mutex<Option<u64>>,

/// Per-transaction write buffer. Keyed by txn_id.

```

Initialize both in `init.rs`:

```rust

```

### Behavioral Changes

#### `begin_transaction()` (ops.rs:104)
- Generate txn_id (same as today)
- **Set** `*active_txn_id.lock() = Some(txn_id)`
- **Do NOT** write `Begin` to WAL yet (deferred to commit)
- Return txn_id

#### `insert()` (ops.rs:145)
- Check `active_txn_id`:
  - If `None` → existing direct-I/O path (unchanged)
  - If `Some(txn_id)` → `BufferedWrite::Insert(node.clone())` pushed to `txn_buffers[txn_id]`
  - **Skip**: WAL append, vstore write, KV backend put, HNSW add, volatile cache insert, cardinality stats, edge index, scalar index
  - Return `Ok(())`
- **ponytail:** Inside a txn, we skip indices too — cardinality stats, edges, scalars are rebuilt on commit. This is correct for the simple case; add eager index updates inside txn only if read-your-writes needs filtered queries.

#### `delete()` (ops.rs:760)
- Check `active_txn_id`:
  - If `None` → existing direct-I/O path (unchanged)
  - If `Some(txn_id)` → `BufferedWrite::Delete(id)` pushed to `txn_buffers[txn_id]`
  - **Skip**: all store I/O
  - Return `Ok(())`

#### `commit_transaction()` (ops.rs:118)
```rust
pub fn commit_transaction(&self, txn_id: u64) -> Result<()> {
    // 1. Drain buffer
    let buffer = {
        let mut active = self.active_txn_id.lock();
        if *active != Some(txn_id) {
            return Err(VantaError::invalid_operation(
                "transaction not active or mismatch"
            ));
        }
        *active = None;
        let mut buffers = self.txn_buffers.lock();
        buffers.remove(&txn_id).unwrap_or_default()
    };

    if buffer.is_empty() {
        // Empty txn: just append Commit marker
        if let Some(ref sharded) = self.wal {
            sharded.append(&WalRecord::Commit(txn_id))?;
        }
        return Ok(());
    }

    // 2. Build WAL batch: Begin + all ops + Commit
    let mut wal_records = Vec::with_capacity(buffer.len() + 2);
    wal_records.push(WalRecord::Begin(txn_id));
    for op in &buffer {
        match op {
            BufferedWrite::Insert(node) => wal_records.push(WalRecord::Insert(node.clone())),
            BufferedWrite::Delete(id) => wal_records.push(WalRecord::Delete { id: *id }),
        }
    }
    wal_records.push(WalRecord::Commit(txn_id));

    // 3. Write WAL batch (single fsync)
    if let Some(ref sharded) = self.wal {
        sharded.batch_append(&wal_records)?;
    }

    // 4. Apply to stores (same logic as today's insert/delete but in a batch)
    for op in &buffer {
        match op {
            BufferedWrite::Insert(node) => {
                // Reuse existing logic: extract the store-apply portion
                self.apply_insert(node)?;
            }
            BufferedWrite::Delete(id) => {
                self.apply_delete(*id)?;
            }
        }
    }

    Ok(())
}
```

**Note:** You'll need to refactor `insert()` and `delete()` into two parts:
1. The "hot path" wrapper (checks active_txn_id, either buffers or calls apply)
2. The `apply_insert()`/`apply_delete()` methods (pure store I/O, no buffering check)

Or, more minimally: extract the store-I/O section of `insert()` into a private `apply_insert_unchecked()` method, then call it from both `insert()` and `commit_transaction()`.

#### `abort_transaction()` (ops.rs:129)
```rust
pub fn abort_transaction(&self, txn_id: u64) -> Result<()> {
    let was_active = {
        let mut active = self.active_txn_id.lock();
        let is_active = *active == Some(txn_id);
        if is_active {
            *active = None;
        }
        is_active
    };

    if was_active {
        // Discard buffer
        self.txn_buffers.lock().remove(&txn_id);
        // Append Abort marker
        if let Some(ref sharded) = self.wal {
            sharded.append(&WalRecord::Abort(txn_id))?;
        }
    } else {
        // Non-active txn: just append Abort (Phase 1 behavior)
        if let Some(ref sharded) = self.wal {
            sharded.append(&WalRecord::Abort(txn_id))?;
        }
    }
    Ok(())
}
```

#### `get()` (ops.rs:530) — Read-your-writes
Before the existing logic (cache check → backend → vstore), add:

```rust
// Read-your-writes: check active txn buffer first
{
    let active = self.active_txn_id.lock();
    if let Some(txn_id) = *active {
        let buffers = self.txn_buffers.lock();
        if let Some(buffer) = buffers.get(&txn_id) {
            // Scan backwards for the most recent write to this ID
            for op in buffer.iter().rev() {
                match op {
                    BufferedWrite::Insert(node) if node.id == id => {
                        return Ok(Some(node.clone()));
                    }
                    BufferedWrite::Delete(del_id) if *del_id == id => {
                        return Ok(None);
                    }
                    _ => {}
                }
            }
        }
    }
}
```
