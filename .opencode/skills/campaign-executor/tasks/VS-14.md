## Shape del bridge (verificado 2026-08-18, `desktop/src/vanta.ts`)

```ts
versions(key: string, namespace?: string): Promise<MemoryRecord[]>   // ascendente v1..vN
getVersion(key: string, version: number, namespace?: string): Promise<MemoryRecord>
vantaPut({ namespace?, key, payload, metadata?, expires_at_ms? }): Promise<MemoryRecord>  // P6
```

- `MemoryRecord`: `{ id, namespace, text, vector?, metadata?, created_at_ms?, updated_at_ms?, version?, node_id?, sparse_vector?, expires_at_ms? }`
- Cada snapshot histórico es un `MemoryRecord` completo (core `SnapshotRecord` incluye vector/sparse/expires_at_ms — verificado en `src/sdk/version_history.rs:59-128`).
- El último elemento de `versions()` == record actual (snapshot del record nuevo por put).
