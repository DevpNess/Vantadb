## Web research (verificada)

- Tailwind v4 class dark mode: `@custom-variant dark (&:where(.dark, .dark *));` — https://tailwindcss.com/docs/dark-mode (official)
- Vite plugin: `npm install tailwindcss @tailwindcss/vite` + `plugins: [tailwindcss()]` + `@import "tailwindcss";` — https://tailwindcss.com/docs/installation/using-vite (official)
- Gotcha `@theme inline`: las utilities referencian `var(--background)` (no el literal), por eso override en `.dark` SÍ flipea — mismo patrón shadcn/globals.css (fuente: tailwindlabs discussion #16517)
- Fuentes locales (fontsource woff2, 8 URLs verificadas 200 OK el 2026-08-18): Anton 400, Space Mono 400/700, Geist Sans 400/500/600/700, Geist Mono 400 — vía `https://cdn.jsdelivr.net/npm/@fontsource/<pkg>/files/<file>.woff2`
- **`ink-corner` NO existe en globals.css** → NO se replica; se define como utility propia solo si una task futura la necesita (YAGNI)
