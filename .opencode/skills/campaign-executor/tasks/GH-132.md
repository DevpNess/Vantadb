## SDK APIs used (verified)

Sourced from `docs/api/PYTHON_SDK.md`. Package name `vantadb-py`, import `vantadb_py` (underscore).
- `vanta.VantaDB(db_path, memory_limit_bytes=...)` — constructor
- `db.put(namespace, key, payload, metadata=, vector=)` — insert/update
- `db.get_memory(namespace, key)` → record with `.payload`, `.metadata`
- `db.search_memory(namespace, query_vector=, text_query=, filters=, top_k=)` — hybrid search; hits have `.key`, `.score`, `.payload`
- `db.list_memory(namespace, filters=, limit=)` — metadata-filtered list, `.records`
- `db.delete_memory(namespace, key)` — delete
- `db.flush()` / `db.close()`

Notebook pipeline: install → open db → put (3 records with metadata + vector) → get → hybrid search (vector+text, RRF) → metadata filters (list + search) → update/delete → flush/close.
