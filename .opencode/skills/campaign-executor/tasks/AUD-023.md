**Decisión (doubt-driven):** se valida `is_finite()` (cubre ±inf y NaN), `>= 0`, `<= u32::MAX as f64` y `fract() == 0.0` (dims no-enteros). El truncado silencioso de `1.5 as u32 → 1` es el mismo bug class que el finding (pérdida silenciosa de datos). `u32::MAX as f64` es exacto (2^32-1 < 2^53). Weights `f32` NO se validan — fuera del contrato P2-7 (solo dims); NaN en weight es un finding aparte si alguien lo reporta.
