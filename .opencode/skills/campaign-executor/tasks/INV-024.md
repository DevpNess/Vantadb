# INV-024: Auditar bloques `unsafe` sin SAFETY docs

**Fuente:** Backlog.md Phase 1 — Security & Critical
**Prioridad:** 🟠 Alta | **Esfuerzo:** 🟡 3-5 días
**Tipo:** Investigación + Propuesta (sin implementación)
**Sub-agente:** `vanta-audit`

## Descripción

Revisar todos los bloques `unsafe` en el código Rust que carecen de SAFETY comments documentando invariantes. Determinar si hay UB potencial o si son seguros pero sin documentar. Proponer: (a) agregar SAFETY comments, o (b) reemplazar con alternativas seguras.

## Contexto

Hay ~52 bloques `unsafe` en el core de Rust, distribuidos así:

| Archivo | # unsafe | Naturaleza |
|---------|----------|------------|
| `src/storage/vfile.rs` | ~12 | Mmap, MmapMut, signal handlers (SIGSEGV), libc FFI, Windows API |
| `src/index/distance.rs` | ~15 | `unwrap_unchecked` en chunks SIMD `[f32;8]`/`[f32;16]`, `from_raw_parts` |
| `src/index/graph.rs` | ~4 | Operaciones mmap HNSW, acceso a memoria mapeada |
| `src/index/serialize.rs` | ~5 | `from_raw_parts`, `MmapMut::map_mut`, reinterpretación bytes→f32 |
| `src/index/search.rs` | ~2 | Cast raw pointers a `&[f32]` para vectores |
| `src/index/ivf.rs` | ~1 | `from_raw_parts` sobre mmap IVF |
| `src/node.rs` | ~1 | `from_raw_parts` para vectores en nodos |
| `src/storage/archive.rs` | ~4 | Mmap en shadow archive |
| `src/storage/engine/ops.rs` | ~4 | Cast raw pointers a `&[f32]` |
| `src/storage/engine/maintenance.rs` | ~2 | `MmapMut::map_mut`, unsafe block |
| `src/metrics/core/mod.rs` | ~2 | Unsafe blocks en metrics |

**Solo 3 bloques tienen `// SAFETY:` comments:** `accumulator.rs` (2) y `vfile.rs` (1 envuelto en mod test).

## Acceptance Criteria

- [ ] Cada bloque `unsafe` es revisado y clasificado como:
  - ✅ **Documentable** — seguro pero sin SAFETY comment → propuesta de comment
  - ❌ **UB potencial** — necesita reemplazo con alternativa segura → propuesta de fix
- [ ] Se produce un reporte con:
  - Mapa completo: archivo:línea → clasificación → riesgo
  - SAFETY comments propuestos para los documentables
  - Alternativas seguras propuestas para los UB potenciales
  - Vulnerabilidades clasificadas por severidad (High/Medium/Low)
- [ ] No hay implementación — solo auditoría + propuesta
