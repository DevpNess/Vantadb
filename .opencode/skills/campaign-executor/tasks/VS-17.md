## PROPUESTA / Decisiones

- **Favorito = `{ namespace, key: string | null }`** — `key: null` es favorito de namespace completo (★ en sidebar), `key` presente es favorito de registro (★ en grid/inspector). Persistencia `localStorage["vanta.favorites.v1"]` como JSON array, newest-first.
- **Store vanilla con suscripción** (mismo patrón `undo.ts`): `getFavorites/isFavorite/toggle/removeNamespace/subscribe` + singleton exportado; clase exportada para el self-check (permite instanciar con storage mock).
- **Storage inyectable con default** `typeof localStorage !== "undefined" ? localStorage : null` — en Node el self-check setea `globalThis.localStorage` mock ANTES del import dinámico; si no hay storage (sandbox), el store funciona in-memory sin persistir.
- **Historial**: `localStorage["vanta.search-history.v1"]`, N=10, dedup no-consecutivo (re-buscar una query la mueve al frente), `add/get/clear/subscribe`. Se graba en `runSearch` (funnel único de topbar + palette → cubre ambos entry points del contrato).
- **Copy-as**: `copy-as.ts` módulo puro (React-free, type-only import de vanta como `logic.ts`) — `recordToJson = JSON.stringify(record, null, 2)`; `recordToMarkdown` = doc markdown compacto (encabezado ns/key, payload, tabla de metadata, pie con version/updated). `copyText` usa `navigator.clipboard.writeText` (Tauri v2 lo soporta) con error descriptivo si no está.
- **Feedback "copiado"**: `CopyButton` swaps su label a "✓ copiado" por ~1.5s (aria-label + title fijos para a11y).
- **Grid**: una sola acción copiar por fila (⧉ → JSON completo — lo más útil de una fila; las 3 variantes viven en el Inspector, que tiene espacio). ★ por fila junto al 🗑 existente.
- **Inspector**: fila compacta de acciones copy-as (JSON / KEY / MD) + ★ en el header; feedback igual.
- **Self-check sin test runner**: `scripts/selfcheck-vs17.mjs` compila los 3 módulos puros con tsc a CommonJS (patrón VS-15), mockea localStorage, y valida: roundtrip favoritos (toggle → reload → persiste), roundtrip historial (add/dedup/cap/clear → reload), shape de recordToJson/recordToMarkdown.
