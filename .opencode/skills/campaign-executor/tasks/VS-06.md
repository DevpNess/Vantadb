## Notas
- **Commit explícito (P6):** el inspector NUNCA auto-guarda. Los edits viven en drafts; el diff del footer lista qué cambió (payload/metadata/TTL); REVERTIR descarta; GUARDAR es el único punto de persistencia. Flash "✓ guardado v{version}" confirma el bump del core.
- **CodeMirror lazy:** `@uiw/react-codemirror` + react-markdown pesan ~566 kB → chunk lazy `Inspector-*.js`; el shell paga solo 317 kB (gzip 98 kB). Warning de chunk >500 kB es del chunk on-demand — aceptable en Tauri local. Code-split adicional (lazy de tabs) = optimización fuera de alcance de Fase 0.
- **Contrato wire metadata:** el KV editor opera sobre el JSON plano que ya viaja por el bridge (DateTime→RFC3339 string, lista→array, objeto→string JSON). Round-trip estable; reordenar filas marca dirty (JSON.stringify compara orden) — aceptado, se mitiga con "ver diff" (solo cuenta keys).
- **Fidelidad de tipos:** float `1.0` → int `1` en round-trip (inferType usa `Number.isInteger`); la UI muestra int y el core recibe `1` — cambio numérico equivalente, documentado como límite aceptado.
- **Sin test infra en desktop/:** los helpers puros (rowsToMetadata/ttlToMs) se verifican por tsc strict + round-trip estable por construcción; no hay vitest configurado (consistente con VS-03/05).
- **nanoid (high) en `npm audit`:** PRE-EXISTENTE (`vite@7.3.6 → postcss → nanoid@3.3.17`), solo build-time, no introducido por estas deps — no tocar en Fase 0.
