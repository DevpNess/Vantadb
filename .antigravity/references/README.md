# Antigravity Reference System

Este directorio contiene la suite completa de guías de referencia de ingeniería importadas de `.antigravity/references/`:

- `definition-of-done.md`: Checklist standing de fin de tarea.
- `security-checklist.md`: Auditoría de seguridad y hardening.
- `performance-checklist.md`: Guía de optimización y benchmarks.
- `accessibility-checklist.md`: Estándares WCAG 2.2 y UX.
- `observability-checklist.md`: Métricas, tracing y logging estructurado.
- `testing-patterns.md`: Patrones TDD, unitarios e integración.
- `orchestration-patterns.md`: Patrones de composición de agentes y subagentes.
- `REFERENCE-SYNTHESIS.md`: Síntesis de referencias de ingeniería.
