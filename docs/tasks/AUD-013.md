## Investigation Notes
`src/index/neighbor_index.rs` tiene **0 funciones #[test] y 0 mod tests** (verificado en audit). La invariante INV-024 (contador `inbound` = número de referencias entrantes a cada nodo) se implementó sin cobertura unitaria directa. 12 call-sites mutan el contador (líneas 46-231). Un decrement olvidado produce islas silenciosas (datos inalcanzables sin UB).

Tests a añadir (en `src/index/neighbor_index.rs`, nuevo `#[cfg(test)] mod tests`):
1. insert → `inbound_count(id) == 1`
2. `set_neighbors` replace → decrementa viejo + incrementa nuevo
3. remove → limpia entry
4. **Property test**: después de secuencia aleatoria de insert/replace/remove, la suma de `inbound` == total de aristas en todas las listas
5. Regresión: nodo con exactamente 1 inbound sobrevive al shrink (si el test necesita graph.rs, coordinar — ver Notas)

IMPORTANTE: la invariante es internamente consistente — los tests deben construir `HnswNeighborIndex` directamente (métodos `#[cfg(test)]` disponibles o públicos del crate).
