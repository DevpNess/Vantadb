### Step 1: Reemplazar expect de GovernorConfigBuilder
- **Archivos:** `src/cli_server.rs:154-164`
- **Acción:** Reemplazar `.expect("GovernorConfig build failed")` con `match` que loguea error y degrada a *sin rate limit* (no cambia firma de `app_with_cors`, no toca callers):
  ```rust
  match GovernorConfigBuilder::default()
      .per_millisecond(period_ms)
      .burst_size(burst_size)
      .key_extractor(SmartIpKeyExtractor)
      .finish()
  {
      Ok(gc) => protected.layer(GovernorLayer::new(gc)),
      Err(e) => {
          tracing::error!("Governor config build failed ({e}); rate limiting disabled");
          protected
      }
  }
  ```
