## Investigation Notes
Patrón MVCC típico para embedded DBs en Rust:
1. Transaction IDs monotónicos (ya existe `next_txn_id`)
2. Cada registro metadata: `created_by_txn: u64`, `deleted_by_txn: Option<u64>`
3. Snapshot = txn_id al inicio de la transacción
4. Lectura filtrada: `created_by_txn <= snapshot_txn && (deleted_by_txn IS NULL || deleted_by_txn > snapshot_txn)`
5. Write-write conflict detection (first-writer-wins u optimistic)
6. Garbage collection de versiones viejas (periódico o en checkpoint)

Referencias: txn-db (Rust), nexir-mvcc-core, rosedblabs/rust-practice
