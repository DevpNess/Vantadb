- **Semántica TTL:** el core `put` acepta `ttl_ms` RELATIVO (`expires_at_ms = now + ttl`, api.rs:310); el bridge expone `expires_at_ms` ABSOLUTO (lo que VS-06 edita) y convierte con `saturating_sub(now_ms())`. Edge: un expiry ya pasado → ttl 0 → expira inmediatamente (aceptable, sin error).
