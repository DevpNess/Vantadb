## Steps
### Step 1: parseImport.ts — parser CSV/JSON/NDJSON + runImport chunked (testeable)
- **Archivos:** `desktop/src/components/ingest/parseImport.ts` (nuevo), `desktop/src/components/ingest/parseImport.test.ts` (nuevo)
- **Acción:** parser puro `parseImport(text, namespace, limit=1000) → {rows: ParsedRow[], valid, invalid, truncated, error}`. `ParsedRow = {index (1-based), item: IngestItem | null, error?}`. CSV con cabecera (delimitador `,` o `\t` si no hay comas; split con soporte de campos entre comillas `"` básico, RFC-4180; sin campos multilínea — limitación documentada): columnas reconocidas case-insensitive `key|id|node_id` → id, `text|payload|content|message` → text, `metadata|metadata_json` → metadata (JSON.parse, falla → error de fila), `namespace` → override por fila; columnas desconocidas → ignoradas. JSON: array de objetos o objeto único o NDJSON (una línea = un objeto, líneas vacías salteadas); mapeo por campo reconocido; keys restantes → `metadata`; sin campo text → error de fila "falta text/payload/content". Sin formato → `error` global legible. Máx `limit` filas → `truncated: true`. `runImport(items, ingestFn, chunkSize=50) → Promise<ImportReport {imported, errors: {rows, message}[]}>` — chunking secuencial de `ingestBatch` (atómico por llamada: falla de chunk → error con rango de filas).
- **Verify:** `npx vitest run src/components/ingest/parseImport.test.ts` (desktop/) — casos: CSV 10 filas válidas; fila con text faltante marcada invalid sin romper resto; metadata JSON inválido → error de fila; JSON array; NDJSON; objeto único; >1000 → truncated; garbage → error global; runImport: 3 chunks ok → imported=N, un chunk falla → error con rango.
