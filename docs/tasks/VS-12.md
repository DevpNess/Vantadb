## Objetivo

El core YA escribe `AuditEvent{timestamp, op, namespace, key, outcome, reason}` opt-in vía
`VantaConfig.audit_log_path` (`src/audit.rs`); el desktop NO configura audit ni tiene comando
de lectura. Esta tarea: (a) `NativeConnection::open` configura audit por default, (b) comando
`vanta_audit_events` con tail + filtros + cursor, (c) `vanta.ts` tipado, (d) error claro si no
hay audit configurado.
