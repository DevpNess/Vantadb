## Resolución de versiones (método)

Por cada repo con pins sin anotar:
1. `git ls-remote --tags <repo>.git` — lista tags y sus commits (`^{}` dereferencia tags anotados)
2. Si el SHA es tip de tag semver exacto (`v4.6.2`, `v5.6.0`, etc.) → usar esa versión
3. Si no, `git clone --filter=blob:none` + `git describe --tags` → tag ancestral más cercano (`Swatinem/rust-cache@7e35be21 → v2.9.1`, `taiki-e/install-action@25f25a6e → v2.83.4`, `attest-build-provenance@78e6cbd3 → v4.1.1`)
4. dtolnay/rust-toolchain no tiene tags semver (solo `v1` de 2025-08-23, commits de 2026 son post-tag en master) → anotar `# v1` (el único tag del repo)
