## Notas
- **Fuente de datos limitada por el bridge (honesto, no inventado):** `vanta_list` sin namespace → solo namespace `default`; sin comando `vanta_list_namespaces` ni `namespace_stats` en el bridge → "Por namespace" muestra lo que devuelve list (hoy: `default`), "Expirados recientes" siempre 0 (list excluye expirados via `memory_record_from_node`). Cuando el bridge exponga `namespace_stats` (VS-CORE-02), esta componente swapea la fuente: `{namespace: {count, expiring_soon, expired}}` → puebla namespace + expiring + expired sin N list().
- **Ponytail:** sin estado global nuevo (zustand queda para VS-08); sin fetch per-card (UNA llamada list por refresh); sin componente genérico de card reutilizable fuera del archivo (2 usos, YAGNI); el hook vive dentro del mismo archivo (nadie más lo consume).
- **"Tendencia" = proxy honesto:** el core no tiene delta histórico en el bridge; la card muestra `▲ actualizados / 7d` (derivado de `updated_at_ms`), no un % de crecimiento inventado.
- **A11y:** encoding redundante en todas las cards (color + ícono + texto); botón refresh con `aria-label`; barras con `aria-hidden` (el % va como texto); `:focus-visible` neon de VS-01 aplica al botón.
- **Server backend (HTTP/IQL):** VS-11 advierte que timestamps/expires llegan `null` desde el adapter server → actividad/TTL muestran vacíos honestos (guards `!= null`); sin crashes.
- **No testeado en runtime visual** (dev server + Tauri no levantados en esta sesión): validado por tsc strict + build; la verificación visual (Playwright) queda para el flujo del lead.
