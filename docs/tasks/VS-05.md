## Notas
- **TanStack Table v9 es un rewrite mayor (v8 → v9):** no hay `useReactTable`; el `tableFeatures()` registra features Y sortFns/filterFns; `createColumnHelper` tiene 2 generics (`<typeof features, TData>`); `SortFn`/`FilterFn` reciben rows. Validado contra d.ts instaladas — no confiar en docs de v8.
- **Infinite scroll vs filtros:** la condición original (`lastVirtualIndex >= rowCount - 3`) dispararía fetch infinito con un filtro de columna que deja pocas filas (rowCount chico, sin scroll real). Fix: exige overflow (`total > sr.height`) + fondo real del viewport (`offset + sr.height >= total - 80`) — un filtro que deja 3 filas no tiene overflow y no fetchea. Nota: con filtro activo el "scroll to load more" sigue existiendo (solo data cargada), comportamiento deliberado.
- **Search mode:** one-shot `search({query, top_k: 200})`, sin cursor, sin load-more — el effect de infinite scroll corta con `mode !== "list"`.
- **`getRowId: (r) => ${r.namespace}:${r.id}`** — estable entre páginas (los rows de fetchMore se appenden, React reconcilia por id).
- **Self-managed state:** `useTable` sin `state`/`atoms` — sort/filter se mantienen entre fetches de cursor (data append no resetea el estado de tabla).
- **Virtualización real:** `<tbody style={{height: getTotalSize()}}>` + filas absolute con translateY; solo ~visible+overscan se renderizan; thead sticky fuera del flujo virtual.
- **Live TTL:** interval 30s → `setNow` re-render → `TtlCell`/`relTime` recomputan contra `Date.now()` (barra countdown y "X left" se mueven sin refetch).
- **Ponytail:** sin hook custom, sin state management nuevo, sin abstracciones de tabla — `helper.columns` es el único patrón requerido por v9 para columnas heterogéneas; el grid reutiliza tokens CSS existentes.
