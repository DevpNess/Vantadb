# AUD-026 — Default features arrastran cli/arrow/tantivy al DLL nativo

## DISCOVERY

- **Backlog:** docs/Backlog.md:428 — `AUD-026 | Media | default features arrastran cli/arrow/tantivy al DLL nativo (6.7MiB debug; lsm_tree+fjall 944KiB) — build extension con --no-default-features | Cargo.toml:97 | ⏳ pendiente`
- **Tipo:** devops (CI/CD / packaging)
- **Archivos clave:** `Cargo.toml:97` (workspace `[features] default`), `vantadb-node/Cargo.toml:24`

### Análisis del hallazgo

`Cargo.toml:97` define `default = ["cli", "arrow", "fjall", "roaring", "advanced-tokenizer", ...]`.
Cualquier crate que dependa de `vantadb` **sin** `default-features = false` arrastra
`cli`, `arrow` y `tantivy` (vía `advanced-tokenizer`) a su artefacto.

Estado por binding (verificado en 2026-08-14):

| Crate | Artefacto | Dep vantadb | default-features = false? |
|---|---|---|---|
| `vantadb-python` | DLL PyO3 | `["fjall","memmap2","rayon"]` | ✅ sí (commit aaf0428) |
| `vantadb-wasm` | WASM | `["wasm"]` | ✅ sí |
| `vantadb-node` | DLL napi-rs (cdylib) | `["fjall","memmap2","rayon"]` | ❌ **NO — el bug** |
| `vantadb-mcp` | binario CLI | `["cli"]` | correcto (es CLI) |
| `vantadb-server` | binario CLI/server | `["cli","server"]` | correcto (es binario) |

**Root cause:** `vantadb-node/Cargo.toml:24` — `vantadb = { path = "..", features = ["fjall", "memmap2", "rayon"] }`
sin `default-features = false` → el addon nativo de Node incluye cli/arrow/tantivy.
