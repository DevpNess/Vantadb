## Análisis por Crate

### 1. atomic-polyfill (RUSTSEC-2023-0089)

- **Tipo:** Transitiva
- **Traída por:** `vantadb → postcard v1.1.3 → heapless v0.7.17 → atomic-polyfill v1.0.3`
- **Target-specific:** Solo aparece en builds con `--target all` (no en host nativo). Dependencia condicional de `heapless`.
- **Advisory:** Unmaintained. La crate no recibe mantenimiento pero no tiene vulnerabilidad de seguridad conocida.
- **Estado actual:** Ya ignorada en `deny.toml` línea 3-9 con expiry 2027-01-01.
- **Mitigación documentada:** `postcard` v2.0 migra a `heapless` v0.9+ que usa `portable-atomic` (ya presente como dependencia directa en VantaDB).
- **Propuesta:** ✅ **Mantener ignore**. Trackear upgrade a postcard 2.0 cuando esté disponible.
- **Riesgo:** 🟢 Bajo — no es seguridad, solo mantenimiento.

### 2. paste (RUSTSEC-2024-0436)

- **Tipo:** Transitiva
- **Traída por:** `ratatui` y `tikv-jemalloc-ctl` (ambas feature-gated — TUI y jemalloc prof)
- **Advisory:** `paste` — crate **INFO** (unmaintained). El README indica que está archivado. No es vulnerabilidad de seguridad — es un aviso de que no recibirá más parches.
- **Riesgo real:** 🟢 **Ninguno.** `paste` es un proc macro de compilación. No está expuesto a runtime ni a input externo. El TAD (type of advisory) es INFO, no UNSOUND ni SECURITY.
- **Alternativas:** `pastey` (fork activo), `with_builtin_macros`. Pero el reemplazo depende de `ratatui` y `tikv-jemalloc-ctl`, no de VantaDB.
- **Propuesta:** ✅ **Mantener ignore en deny.toml** (INFO no requiere acción). Trackear upgrades de `ratatui` que migren de `paste`.
- **Riesgo:** 🟢 Ninguno — solo build-time.

### 3. rustls-pemfile (RUSTSEC-2025-0134)

- **Tipo:** ~~Transitiva~~ **No es dependencia activa.**
- **Advisory:** `rustls-pemfile` permite "Advanced File Globbing" que puede leer archivos arbitrarios.
- **Estado real:** No existe en ninguna dependencia del workspace. `cargo tree -p rustls-pemfile` → `error: did not match any packages`.
- **Propuesta:** ✅ **Remover del backlog** — no es riesgo activo.
- **Riesgo:** 🟢 Ninguno.
